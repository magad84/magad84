# GitHub Profile Governance

## Purpose

This repository governs the public GitHub profile for Mostafa Gad.

The profile is positioned as an executive and business transformation presence, not as a software-developer portfolio.

## Positioning

Primary positioning:

Executive Management & Operations Leader | Supply Chain | Business Transformation | AI-Enabled Execution

GitHub should demonstrate how executive and domain expertise is translated into governed digital products, applied AI, automation workflows, research-backed tools, and decision-support systems.

## Public Profile Rules

- Keep the profile concise, professional, and evidence-led.
- Avoid developer-centric vanity metrics such as language charts, streak counters, and excessive technology badges.
- Use public repositories only when they are approved for public exposure.
- Do not expose private implementation assets, internal research, proprietary prompts, confidential business records, infrastructure details, or unapproved product material.
- Prefer public showcase repositories over making production repositories public when the product contains proprietary or commercial implementation.
- Keep repository boundaries independent. Do not merge product repositories for presentation purposes.
